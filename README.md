# NEO LEARN — AI + Electronics + Language Update

This GitHub Pages-ready package keeps the NEO LEARN purple/black design, 16-week curriculum, progress tracking, achievements, and bundled projects.

## Included updates
- Electronics Course: electricity basics, components and sensors, Arduino Uno, simulation, projects, and wiring safety.
- AI Course: AI and machine-learning basics, Teachable Machine, Python foundations, model training/testing, AI projects, and responsible AI.
- NEO Learning Assistant: a local guided educational demo with topic-based explanations. It is **not connected to an external AI API** in this version.
- Interactive AI quiz with three questions and immediate scoring.
- EN / عربي language toggle beside the theme button; it switches the main interface, Electronics Course, and AI Course. The original detailed 16-week lesson content is preserved and remains primarily in its original language.
- Existing project files and progress/achievement features are retained.

## Publish on GitHub Pages
Upload/replace the package contents in the repository used by `https://ea692738-dotcom.github.io/Eyad/`. Keep the `projects` folder and its files in place.

## Note about the learning assistant
The built-in assistant uses local guided answers for common topics. For real generative AI responses, a secure backend/API integration would be needed; do not put private API keys in public GitHub Pages JavaScript.


## NEO Smart Home (Arduino Uno)

The `NEO_Smart_Home_Project/` folder contains the Arabic project plan, suggested pin map, component list, test checklist, and starter Arduino sketches for the password door, ultrasonic garage, and integrated starter example. These are prototypes and must be tested with the actual hardware; do not connect household mains voltage directly to Arduino. The project is linked in the Projects section.
