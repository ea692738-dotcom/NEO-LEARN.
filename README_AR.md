# NEO Smart Home — مشروع المنزل الذكي

**اللوحة:** Arduino Uno  
**طريقة التنفيذ:** ابدأ بالمحاكاة أو باختبار كل جزء منفردًا، ثم ادمج الأنظمة تدريجيًا.

> **مهم:** هذه حزمة مشروع منظمة وبداية عملية، وليست نظامًا متكاملًا تم اختباره على جهاز حقيقي. يجب مراجعة التوصيلات وتعديلها حسب القطع الفعلية قبل توصيل الطاقة. لا توصل أحمال المنزل الكهربائية مباشرة بالأردوينو؛ استخدم وحدات قيادة مناسبة وبإشراف شخص بالغ مؤهل.

## محتويات الحزمة
- `PROJECT_PLAN_AR.md` — تصميم المشروع ومراحل التنفيذ.
- `COMPONENTS_AR.csv` — قائمة المكونات.
- `PIN_MAP_AR.md` — خريطة الأرجل المقترحة.
- `code/Password_Door.ino` — نموذج قفل باب بكلمة مرور عبر Keypad وسيرفو.
- `code/Garage.ino` — نموذج باب جراج بمستشعر مسافة وسيرفو.
- `code/Integrated_Starter.ino` — نقطة بداية تجريبية للإضاءة والحركة والتنبيه.
- `TEST_CHECKLIST_AR.md` — قائمة اختبار قبل الدمج.

## ترتيب العمل المقترح
1. اختبر كل دائرة على حدة.
2. جرّب الكود في المحاكاة إذا كانت القطع متاحة فيها.
3. اختبر السيرفو ومصدر طاقته منفصلين عند الحاجة، مع توحيد GND وفق تعليمات القطع.
4. ادمج الوحدات واحدةً تلو الأخرى.
5. لا تعتبر المشروع مكتملًا قبل اختبار كل وظيفة فعليًا.

## مكتبات الأكواد المنفصلة
- كود الباب يستخدم `Keypad` و`Servo`.
- كود الجراج يستخدم `Servo`.
- كود البداية يستخدم `Servo` فقط إذا احتجت لاحقًا إضافة آلية حركة؛ النسخة الحالية لا تستخدمه.
